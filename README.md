# 🎮 Tic Tac Toe – Jeu en JavaScript

Un petit projet **Tic Tac Toe** (Morpion) développé en **HTML**, **CSS** et **JavaScript** vanilla. Idéal pour les débutants souhaitant comprendre la manipulation du DOM, la gestion d'événements et la logique de jeu de base.

---

## 📂 Structure du projet
/pubic │ ├── css/ │ └── app.css ← Style du jeu │ ├── js/ │ └── app.js ← Logique JavaScript │ └── index.html ← Fichier principal HTML
---

## ▶️ Fonctionnalités

- Tour par tour : "O" et "X"
- Détection automatique du gagnant
- Affichage du gagnant ou "Match Drawn" en cas d'égalité
- Boutons pour :
  - **Nouvelle partie**
  - **Réinitialisation**

---

## 🧠 Technologies utilisées

- **HTML5** – structure du jeu
- **CSS3** – mise en page simple et responsive
- **JavaScript** – logique du jeu (sans framework)

---

## ✅ Comment jouer

1. Clique sur une case vide pour jouer.
2. Le jeu alterne automatiquement entre les joueurs O (vert) et X (noir).
3. Un message s’affiche en cas de victoire ou d’égalité.
4. Utilise le bouton **Reset Game** ou **New Game** pour recommencer.
